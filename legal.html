3. Payments (x402 / USDC) — Finality

Paid endpoints use the HTTP 402 (x402) standard. Each request is priced in USDC on Base Mainnet and paid to the wallet address shown in the 402 response. Two payment methods are accepted:

  • Signed authorization (X-PAYMENT): the authorization is verified and settled only after your request has been validated and the result has been computed.
  • On-chain receipt (X-Payment-Receipt): you send USDC on Base first and present the transaction hash. The receipt is consumed only when the response is delivered.

Finality. Once the payment authorization has been verified and the API response has been delivered to you, the payment is final and non-refundable. Blockchain transactions are irreversible.

Errors. If a request is rejected (for example a 4xx validation error) or the server returns a 5xx error before data is delivered, the settlement is not executed or completed. Under the receipt method, a transaction hash that was not consumed can be presented again to retry the request. Network fees are paid by the payer and are not refundable.

If you believe a payment was settled without a response being delivered, contact us with the transaction hash.
